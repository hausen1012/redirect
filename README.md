# URL 重定向服务

一个简单高效的 URL 重定向服务，允许用户通过简单的 URL 格式快速跳转到目标网站。

## 功能特点

- 🚀 极简设计，快速跳转
- 🎨 现代简洁的用户界面
- 📱 响应式设计，支持移动设备
- 🔒 安全可靠的重定向机制

## 使用方法

1. 在 URL 后直接输入目标网址即可实现跳转
2. 格式：`/https://目标网站.com`
3. 示例：访问 `/https://www.amjun.com` 将跳转到 www.amjun.com

## 技术栈

- 前端：HTML5, CSS3
- 字体：Inter (Google Fonts)
- 设计：现代简约风格
